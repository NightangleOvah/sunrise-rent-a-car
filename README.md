# Sunrise Rent a Car & Cabs

Cinematic Sri Lankan transport landing page and WhatsApp booking interface.

## Included

- Responsive mobile-first layout with `100dvh` viewport handling.
- Procedural Three.js vehicle showroom with van, sedan and SUV forms.
- Adaptive renderer pixel ratio based on frame timing.
- Touch and pointer interaction for the 3D showroom.
- Fleet selection pre-fills the booking vehicle.
- Airport, private hire and island-tour sections.
- WhatsApp booking packet generation.
- Live elapsed-time display from 2023-01-01 Sri Lanka time.
- Procedural visuals with no vehicle image downloads required.

## WhatsApp dispatch

The booking action currently targets Sunrise Rent a Car's publicly listed WhatsApp contact `+94 77 638 0753`.

## Hosting

The repository is structured as a static site. GitHub Pages can serve `index.html` directly after Pages is enabled for the repository's `main` branch.
